# Notebooks

Use this folder for exploratory analysis, data profiling, feature experiments, and model comparison notebooks.

Notebook code can be messy while exploring, but anything needed by the production pipeline should be moved into `src/`.

## Colab Notebook

- `mdrtb_treatment_outcome_model_colab.ipynb`: Google Colab workflow for dataset loading/generation, EDA, target definition, model training, evaluation, interpretation, artifact export, and academic limitations.
